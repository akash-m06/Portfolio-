# Akash M — Data Science Portfolio

A responsive one-page portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — portfolio structure/content
- `style.css` — responsive styling, animations and visual system
- `script.js` — scroll reveal, cursor glow, progress bar and mobile menu

## Run
Open `index.html` directly in a browser. No build tools are required.
